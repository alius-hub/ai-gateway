# 前端开发规范

适用于 `frontend/` 下的新增及修改。后续确定的前端开发规范统一补充到本文件，并同步落实到相关页面。

## 表格操作与危险操作

- 表格“操作”列使用无边框、无底色的文字按钮，保留清晰的悬停、键盘焦点和禁用状态；不要使用默认的填充按钮。展示型表格无需添加操作列。
- “编辑”“连接配置”“启用”等常规操作使用页面的品牌色；“停用”“删除”“移除”等危险操作使用醒目的红色文字，只在当前操作确实危险时应用，不能依赖 `:last-child` 判断。
- 危险操作保留确认弹窗；确认按钮使用红底白字，悬停时加深，取消按钮保持普通样式。启用等非危险操作的确认按钮保持原有品牌色。只改变呈现方式，不改变权限、禁用状态或原有点击逻辑。

## 通用界面

- 列表分页统一使用 `AppPagination`，支持记录总数、页码、首页/末页、跳页和每页条数；变更每页条数或筛选条件时重置到第一页并重新查询。后续新增与修改的列表均沿用此格式。
- 列表中的 API Key 必须使用服务端返回的脱敏值，仅显示前 8 位和后 4 位，中间隐藏；日志优先显示调用时的脱敏快照，历史缺失信息明确提示，不向列表返回完整密钥。

- 必填表单项在标签旁显示红色星号，并设置对应的 `required` 或表单校验；条件必填项随条件更新标识。已保存且无需重复输入的密钥须提示“已配置，留空表示不修改”。后续新增和修改的表单均遵循此规则。

- 所有弹窗使用 `frontend/src/styles/index.css` 的 `app-modal-overlay` / `app-modal-panel` 规范，在视口中央显示；确认弹窗沿用统一的居中布局。
- 弹窗点击遮罩关闭统一使用 `v-backdrop-close`，只在按下和点击均发生于遮罩时关闭；不得使用 `@click.self`，避免在弹窗内选中文字、拖动到外部松开时误关闭。关闭回调继续保留提交中等状态限制。
- 下拉选择统一使用 `AppSelect`（其内部应用 `.app-select` 样式），避免不同页面的选择控件外观不一致。
- 管理页保持统一的间距、卡片和按钮风格；列表在切换页面或菜单时清理旧数据，避免残留。
- 管理台内容区域使用全宽布局，勿重新设置全局最大宽度。

## 开发联调

- 前端 API 使用相对路径；Vite 开发代理须将 `/api` 和 `/v1` 转发到后端（默认端口 8001）。
- 修改后至少运行 Vue 类型检查；页面视觉及交互效果由使用者在浏览器中验收。
